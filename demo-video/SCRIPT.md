# HackStop demo script

0–4 seconds: HackStop. A self-hosted hackathon portal.

4–9 seconds: Projects live in a searchable public gallery.

9–14 seconds: Organizers invite judges, set the rubric, and track reviews.

14–19 seconds: Judges see assigned projects and update their own scores.

19–24 seconds: Normalized rankings and CSV export keep the result ready for review.

This is a silent walkthrough with on-screen captions. Every pictured screen is captured from the running portal.
